# PP–NF model materials

Private working repository for Mark Chrisman’s PP–NF model materials. The source record lists the supplied draft, scripts, datasets, and supporting documents.

## Retrieve the complete Zenodo file set

The Zenodo record is public and lists 23 files. To download all of them into `data/zenodo/24050201/`, run:

```bash
python3 scripts/download_zenodo_record.py
```

The script also saves the record metadata as `record.json` and checks file checksums when Zenodo provides them. Python 3 is required; no third-party packages are needed.

Source: [Zenodo record 24050201](https://doi.org/10.5281/zenodo.24050201). The record metadata identifies the license as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); retain attribution and license information when redistributing its files.

## Scientific status

The PP–NF materials describe a proposed framework. They are not independent experimental validation, peer-reviewed acceptance, or scientific consensus. The supplied webpage text explicitly distinguishes proposed claims from established physics and flags open derivations and consistency checks. See [`SOURCES.md`](SOURCES.md) for the source inventory.
